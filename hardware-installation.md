# Hardware Installation

This guide will walk you through the physical installation of your Kratos front button panel replacement.

## Prerequisites

- Kratos kit with all components
- Compatible original Xbox
- Phillips head screwdriver
- Anti-static precautions (recommended)

## Installation Steps

### Step 1: Prepare Your Workspace

1. Work in a clean, well-lit area
2. Use an anti-static mat if available
3. Organize your Kratos components and tools

### Step 2: Open Your Xbox

1. Remove all cables from your Xbox
2. Remove the screws from the bottom of the Xbox
3. Carefully remove the top case
4. Disconnect the power supply if needed for safety

### Step 3: Remove the Original Front Panel

1. Locate the original front button panel
2. Disconnect any existing front panel connections
3. Remove the original front panel board

### Step 4: Install Kratos Main Board

1. Position the Kratos Main Board in place of the original front panel
2. Connect the Front Panel Harness to the main board
3. Secure the board in place

### Step 5: Install Controller Boards

1. Install the 2x Kratos Controller Boards in the controller port locations
2. Connect the Controller Board Connection Cables to each board
3. Ensure all connections are secure

### Step 6: Connect Modxo Harness

1. Connect the Modxo Harness to the Kratos Main Board
2. Route the harness to your Modxo board location
3. Connect to your Modxo board (if applicable)

### Step 7: Reassemble

1. Double-check all connections
2. Replace the Xbox top case
3. Secure with screws
4. Reconnect all cables

## Next Steps

Once hardware installation is complete, proceed to [WiFi Setup](wifi-setup.md) to configure your Kratos connection.
